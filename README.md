# 🐦 Birds on My Hands

손바닥을 펴면 손그림 새가 날아와 앉는 웹 AR 카메라.

앱 설치 없이 브라우저에서 바로 실행됩니다. 인스타그램 릴스에서 유행하는
"실사 영상 + 손그림 캐릭터 합성"을 웹에서 실시간으로 만들어보는 프로젝트예요.

**▶ 데모**: https://yuemyname.github.io/birds-on-my-hands/

## 이런 걸 할 수 있어요

- ✋ **손바닥 위에 새가 앉아요** — 손을 펴면 화면 밖에서 파닥파닥 날아와 "짹" 하고 착지하고,
  손을 치우면 날아가요. 손을 움직이면 따라오고, 가까이 대면 커져요 (최대 4개 손)
- 🍳 **정수리에는 계란 후라이가** — 고개를 기울이면 주르륵 미끄러지다 떨어지고, 잠시 뒤 새 계란이 떨어져요
- ✏️ **내 그림으로 바꿀 수 있어요** — 브라우저 그림판(펜·마커·형광펜·크레용·스프레이)으로
  직접 그리거나 사진을 올려서, 손바닥/정수리 어디에 붙일지 정하면 끝
- 👁 **그림이 살아있어요** — 12fps 손그림 애니메이션 느낌으로 둥실거리고,
  눈 위치를 지정하면 깜빡이기까지
- ✊ **주먹을 쥐면 찌부** — 새는 납작해지며 >< 찡그리고, 직접 그린 그림은 "빠삭" 소리와 함께
  종이처럼 구겨져요. 펴면 다시 방긋
- ✌️ **V를 하면 그림 전환** — 여러 장 등록했다면 V 제스처로 다음 그림으로 바뀌어요
- 📸 **사진·영상으로 남기기** — 사진 버튼은 바로 공유 시트로, 녹화 버튼은 효과음까지 담긴 mp4로
  (아이폰 사진 앱에서 바로 재생)

## 사용 방법

1. 데모 링크를 열고 (카메라가 있는 폰/태블릿/노트북 아무거나)
2. 원하면 그림을 그리거나 업로드해서 등록하고 — 건너뛰면 기본 새·계란 후라이
3. **카메라 시작** → 손바닥을 펴서 카메라에 보여주세요
4. 주먹도 쥐어보고, 마음에 드는 장면은 **녹화** 버튼으로 저장!
