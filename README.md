# 🐦 Birds on My Hands

손바닥을 펴면 손그림 새가 날아와 앉는 웹 AR 카메라.

앱 설치 없이 브라우저에서 바로 실행됩니다. 인스타그램 릴스에서 유행하는
"실사 영상 + 손그림 캐릭터 합성"을 웹에서 실시간으로 만들어보는 프로젝트예요.

**▶ 데모**: https://birds-on-my-hands-production.up.railway.app

## 이런 걸 할 수 있어요

- ✋ **손바닥 위에 새가 앉아요** — 손을 움직이면 따라오고, 가까이 대면 커져요 (최대 4개 손)
- 🍳 **정수리에는 계란 후라이가** — 얼굴을 인식해서 머리 위에 얹어줘요
- ✏️ **내 그림으로 바꿀 수 있어요** — 브라우저 그림판(펜·마커·형광펜·크레용·스프레이)으로
  직접 그리거나 사진을 올려서, 손바닥/정수리 어디에 붙일지 정하면 끝
- 👁 **그림이 살아있어요** — 12fps 손그림 애니메이션 느낌으로 둥실거리고,
  눈 위치를 지정하면 깜빡이기까지
- ✊ **주먹을 쥐면 찌부** — 새가 납작해지면서 >< 하고 찡그려요. 펴면 다시 방긋
- 🎬 **소리까지 녹화** — 버튼 하나로 mp4 저장, 아이폰 사진 앱에서 바로 재생

## 사용 방법

1. 데모 링크를 열고 (카메라가 있는 폰/태블릿/노트북 아무거나)
2. 원하면 그림을 그리거나 업로드해서 등록하고 — 건너뛰면 기본 새·계란 후라이
3. **카메라 시작** → 손바닥을 펴서 카메라에 보여주세요
4. 주먹도 쥐어보고, 마음에 드는 장면은 **녹화** 버튼으로 저장!
